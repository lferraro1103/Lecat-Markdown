# Lecat Markdown

[English](README.md) · [Español](README.es.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · **Português**

Editor e leitor Markdown offline para **Windows e macOS**, com edição visual, código e pré-visualização, diagramas Mermaid e fórmulas LaTeX com KaTeX. Não exige conta nem conexão para editar e renderizar documentos locais.

**Versão estável: 3.4.0.** [Baixar](https://github.com/lferraro1103/Lecat-Markdown/releases/latest) · [Releases](https://github.com/lferraro1103/Lecat-Markdown/releases)

## Recursos

- Tabelas, tarefas, imagens locais, código destacado e três modos de documento.
- Exportação PDF, HTML, EPUB e PNG; SVG para diagramas; impressão com fonte e escala.
- Explorador com filtro, recentes, criação de arquivos/pastas e criação a partir do texto da área de transferência.
- Inspector de arquivo, restauração de abas, temas claro/escuro/sistema, zoom por gesto e janela sempre no topo.
- Quick Look e compartilhamento nativo no Mac, comando `lecat` e protocolo `lecat://file/…`.
- Permissões para links de outros aplicativos, oito idiomas de interface e atualizações beta opcionais.

## Instalação

Windows 10/11 x64: instalador `Setup-x64.exe` ou ZIP portátil. Mac: DMG para Apple Silicon ou Intel, macOS 13+. Para Monterey, use a [edição macOS 12](https://github.com/lferraro1103/Lecat-Markdown/releases/tag/v3.4.0-macos12.1).

```sh
brew tap lferraro1103/lecat-markdown https://github.com/lferraro1103/Lecat-Markdown
brew install --cask lferraro1103/lecat-markdown/lecat-markdown
```

O idioma pode ser alterado nas configurações. No Mac 3.2.5 ou anterior, instale a edição nova manualmente uma vez para habilitar o atualizador. Os pacotes Mac usam assinatura ad-hoc e não incluem notarização Apple. Consulte o [guia de atualização](docs/UPDATES.md).
