# Lecat Markdown 3.7.0

## Explorador con Finder en macOS

- El panel de archivos muestra los mismos Favoritos de la barra lateral de Finder, en el mismo orden, junto con iCloud Drive.
- Íconos nativos de macOS para archivos y carpetas, incluidas las carpetas con ícono personalizado.
- Nombres localizados (por ejemplo, Aplicaciones) y etiquetas de color de Finder en cada archivo.
- Se ocultan los mismos elementos que oculta Finder: archivos ocultos y paquetes como las apps.
- Todo se lee del sistema sin abrir Finder. Si macOS no permite el acceso, se muestran las carpetas habituales.

## Interfaz más prolija

- Pestañas con nombres abreviados con «…», botón de cierre centrado y desplazamiento con la rueda del mouse.
- El botón de actualizaciones de la barra aparece solo cuando hay una versión nueva; la búsqueda manual sigue en Configuración y en Ayuda.
- Diálogos con título y botón de cierre alineados y el mismo ícono de cierre en toda la aplicación.
- Botones de Configuración y panel de búsqueda del modo Código con el estilo de la aplicación.
- La barra de formato flotante ya no tapa el comienzo del documento.
- El Inspector muestra la misma cantidad de caracteres que la barra inferior y «—» en las fechas de documentos sin guardar.
- Barras de desplazamiento finas que siguen el tema claro u oscuro y filas del explorador con la misma altura.

Windows instalado, macOS y Linux mantienen sus canales de actualización. macOS 12 utiliza
la release separada **3.7.0-macos12.1**. Se conserva la firma ad-hoc de Mac.

## English

On macOS the file panel now mirrors Finder: the same sidebar Favorites and iCloud Drive,
native icons, localized names, Finder tag colors, and the items Finder hides stay hidden,
all read without launching Finder. The interface was polished: ellipsized tab names with a
centered close button and wheel scrolling, the toolbar update button only appears when an
update is available, aligned dialog headers, styled settings and code search, the floating
format bar no longer covers the document, consistent Inspector counts and thinner scrollbars.

## 简体中文

macOS 的文件面板现在与访达一致：相同的边栏个人收藏和 iCloud 云盘、原生图标、本地化名称和标签颜色，并隐藏访达隐藏的项目，无需打开访达。
界面更整洁：标签页名称省略显示、关闭按钮居中、可用滚轮滚动；仅在有新版本时显示工具栏更新按钮；对话框、设置与代码搜索样式统一；浮动格式栏不再遮挡文档。
