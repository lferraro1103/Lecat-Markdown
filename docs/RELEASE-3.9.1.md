# Lecat Markdown 3.9.1

## Español

La cancelación del diálogo de contraseña conserva el estado de apertura cancelada incluso cuando el worker termina de forma asíncrona.

- Lectura de PDF locales sin conexión, en las mismas pestañas y paneles que Markdown. Podés trabajar con MD + PDF o dos PDF.
- Reutiliza búsqueda, zoom, enfoque, inspector, compartir y el índice existente para los marcadores del PDF. No agrega barras ni botones de visor.
- Al enfocar un PDF se ocultan las herramientas de edición, guardar y exportar; al volver a Markdown se restauran.
- Texto seleccionable, búsqueda en varias páginas, contraseña con cancelación y restauración de página y zoom al reiniciar. Las contraseñas no se guardan.
- Menú «+» del explorador en Windows y Mac: **Mostrar PDF en el explorador**, desactivado por defecto. Ocultarlos conserva las pestañas y permite abrirlos desde Abrir o Recientes.
- PDF de solo lectura, hasta 100 MB y 5000 páginas. Los escaneos se visualizan; no se agrega OCR, edición, anotaciones ni impresión propia de PDF.

Incluye instalador y portable de Windows, macOS Intel/ARM64 y Linux AppImage/deb. macOS 12 utiliza **3.9.1-macos12.1**.

## English

Read local PDFs offline in existing tabs and panes, including Markdown + PDF and PDF + PDF. Search, zoom, focus, inspector, sharing and PDF bookmarks reuse the existing controls; Markdown editing actions are hidden while a PDF is focused. Supports selectable text, multipage search, password prompts and page/zoom restoration. Passwords are never saved. Enable PDF visibility in the explorer’s existing “+” menu; it is off by default. Read only, up to 100 MB and 5000 pages, without OCR or PDF editing.

Suporta texto selecionável, senha sem armazenamento e restauração de página/zoom. A exibição de PDF é opcional no menu “+”. Somente leitura, até 100 MB e 5000 páginas, sem OCR ou edição de PDF.
