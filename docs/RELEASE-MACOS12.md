# Lecat Markdown 3.6.0-macos12.1 — Monterey

Compatible con macOS 12, Intel y Apple Silicon. Conserva su canal de actualización firmado; no reemplaza la stable para macOS 13+. Para Monterey usá los DMG o ZIP de esta release.

# Lecat Markdown 3.6.0

## Dos documentos en paralelo

- Arrastrá una pestaña sobre otra o sobre el documento y elegí izquierda/derecha.
- También podés usar el menú contextual de la pestaña.
- Cada panel mantiene edición, historial, modo y desplazamiento independientes.
- El separador permite ajustar los anchos con mouse o teclado.
- Búsqueda, formato, guardado, compartir y exportación actúan sobre el panel seleccionado.
- Volver a un solo panel conserva los documentos abiertos en sus pestañas.
- Se restaura la disposición de los archivos guardados al recuperar la sesión.

## Interfaz y Linux

- Se elimina la franja duplicada de título y ubicación; los datos se despliegan desde la pestaña.
- El estado Guardado/Sin guardar queda junto a la búsqueda.
- La barra de formato vertical derecha deja más espacio al desplazamiento.
- Nuevos paquetes Linux x64: AppImage y `.deb`, con sumas SHA256.

Windows instalado y macOS mantienen sus canales de actualización. En Linux,
la actualización se instala descargando el paquete nuevo. macOS 12 utiliza
la release separada **3.6.0-macos12.1**. Se conserva la firma ad-hoc de Mac.

Más detalles: [documentos en paralelo](DOCUMENTOS-EN-PARALELO.md) y [Linux](LINUX.md).

## English

Open two documents side by side by dragging tabs or using their context menu.
Each pane has independent editing, history, mode and scrolling. Resize the divider;
search, formatting, saving and exporting follow the selected pane. Saved-file layouts
are restored with the session. The compact header moves file details into the tab
and save status beside Search. Linux x64 AppImage and Debian packages are now
available; Linux updates are installed manually. Existing Windows and Mac update
channels are preserved.
