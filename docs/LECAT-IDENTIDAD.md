# Lecat - Markdown · identidad 3.1

La aplicación se renombró a Lecat - Markdown. Icono original de gato creado como SVG y rasterizado en PNG/ICO de nueve tamaños (16–256 px), integrado en ejecutable, ventana y cabecera. El paquete y AppUserModelID reflejan la nueva identidad. La carpeta de datos anterior se conserva para mantener preferencias y borradores.

Verificación: cinco pruebas de núcleo y 34 comprobaciones del ejecutable Lecat - Markdown.exe aprobado; 39 verificaciones. Se mantienen la edición y lectura offline con Chromium incluido. Branding original en branding/Lecat.svg, Lecat.png y Lecat.ico.
