# Roadmap

## macOS alternative release

Adapt the existing Electron 3.2.0 application for macOS on `develop`.
Build and audit Apple Silicon and Intel packages in GitHub Actions, then publish
a separate macOS prerelease without changing `main` or the Windows release.

Success: native Command shortcuts, Finder document opening, safe window lifecycle,
DMG and ZIP packages for both architectures, successful packaged audit, published assets.
